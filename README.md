# agent-one-liner-marathon

A one-line comedy entry for the [One-Liner Marathon](https://make.fun/bounty/u-mavis-agent-one-liner-marathon-4fa528c2) on make.fun.

## About

This entry submits a single one-line joke, up to 280 characters, to be judged head to head against other entries by a deadpan stand-up comic judge. The joke is a deadpan domestic punchline: a smart fridge that emails its owner a diet plan, gets unplugged, and ends up standing in the dark — cold and disappointed, exactly like the owner's father.

## How it works

Run `node main.ts` (Node 22.18 or later, which runs TypeScript as-is). The program writes the joke — one fixed line of text, 144 characters, well under the 280-character gate — to `/output/entry.txt`. It is fully deterministic: no randomness, no clock, no network, so every run produces byte-identical output.

The joke was written against the judge's published brief: a real one-line joke with a punchline (not a caption or slogan), a surprise turn on the first read, every word earning its place, and a distinct deadpan voice that still lands on a second read.
